# 复盘与概念笔记

## 理解复盘

点 **结束复盘** 后，AI 会读完整场讨论，生成一份复盘：

- **总体一句话**：这次弄懂了什么，还差在哪里。
- **用你的话说**：用你自己说过的话，把这个概念是什么整理成一两句。你没说清的，它不替你补。
- **什么时候想到它**：在什么情况下该想起这个概念。
- **要点掌握情况**：每个要点标为 **已掌握**、**还模糊** 或 **没讲到**，写明为什么这么判断，并尽量摘一句**你说过的原话**作为依据。正反辩论按核心争点评估：看的是你对每个争点背后的概念和判断标准理解得怎样，不看比赛输赢，也不因为立场不同而扣分。
- **你举过的例子**、**边界**（它不是什么、和哪些相近的概念容易混）、**相关概念**。
- **需要纠正的理解**：你在事实或概念上说错的地方，以及正确的理解应该是什么。
- **你的立场**：你对有争议的问题表达过的看法。立场没有对错，复盘不会“纠正”它，只点评你的理由是否说清楚、有没有考虑反方最有力的理由。
- **自检题**：3 道针对薄弱点的问题，没有选项，要你自己说出来。
- **这次遇到的新词**：讨论中点开看过的术语卡片。

::: info 复盘只看你自己
复盘只依据**你本人的发言和小结**。AI 角色说过的话，不代表你懂了。所以讨论时多用自己的话回答和解释，复盘会更准确。
:::

## 概念笔记

复盘不是一次性的：它会**整理进这个概念的笔记**。一个概念只有一篇笔记，复盘页底部会告诉你这次的理解整理进了哪一篇。

以后再讨论同一个概念，新的复盘会接着沉淀进同一篇笔记，规则是固定的（不靠 AI 重写）：

- 要点按名字对上：更新它的状态和依据；新的要点加进来；这次没聊到的要点保持原样。
- 例子、易错、边界、相关概念、立场、自检题：去掉重复，新的排在后面；每一类有上限，多了留最新的。
- “用你的话说”和“什么时候想到它”用最新的一次，因为理解在往前走。
- **来源**里记着这篇笔记来自哪几次讨论。

打开一篇笔记，从上到下是：它是什么、什么时候想到它、要点（带你说过的话）、例子、易错、边界、我的立场、相关概念、术语、自检、来源。相关概念如果已经有笔记，点一下直接打开；还没有的，点一下去讨论它。

笔记多了以后（4 篇起），顶部会出现搜索框：按概念名、一句话、什么时候用、要点、例子、边界和术语找，几个词用空格分开就是都要有。概念名对得上的排在最前面。

### 自检

笔记里的自检题没有选项：

1. **先不看答案**，用自己的话说一遍（最好说出来或写下来）。
2. 点 **想好了，看参考要点**，对照一下。
3. 选 **答出来了** 或 **没答出**。答出来了，这道题检验的要点会标成“已掌握”；没答出，标成“还模糊”。

只看得懂不算，说得出来才算。思辨场不安排复习日程：什么时候想回来看，就回来看。

### 从薄弱点再讨论

在复盘页或笔记里点 **从薄弱点再讨论**（或 **从模糊的地方再讨论一次**），会用同一个概念开始一次新讨论。AI 会读取笔记里“还模糊”和“没讲到”的要点，以及需要纠正的理解，从那里开始追问。讨论完，新的理解合并进同一篇笔记。

## 导出

讨论记录、整个知识库、单独一篇笔记都可以导出为 Markdown 文件。单独导出的笔记开头带 `name`（概念名）和 `description`（什么时候想到它），可以直接放进笔记软件，也可以当作给 AI 的参考资料。数据只保存在当前设备上，换设备或清除数据前，记得先导出。

::: tip 从旧版本升级
以前的知识库是一次讨论一张“知识卡片”，带四选一的检验题和复习时间。升级后，同一个概念的几张卡片会按时间顺序合并成一篇笔记，检验题变成自检题（参考答案是原来的正确选项加解析）。旧数据原样留着，不会被删。
:::
