# 复盘与知识库

## 理解复盘

点 **结束复盘** 后，AI 会读完整场讨论，生成一份复盘：

- **总体一句话**：这次弄懂了什么，还差在哪里。
- **要点掌握情况**：每个要点标为 **已掌握**、**还模糊** 或 **没讲到**，并写明依据。正反辩论按核心争点评估：看的是你对每个争点背后的概念和判断标准理解得怎样，不看比赛输赢，也不因为立场不同而扣分。
- **需要纠正的理解**：你在事实或概念上说错的地方，以及正确的理解应该是什么。
- **你的立场**：你对有争议的问题表达过的看法。立场没有对错，复盘不会“纠正”它，只点评你的理由是否说清楚、有没有考虑反方最有力的理由。
- **检验题**：3 道针对薄弱点的单选题，选完立刻看到解析。
- **这次遇到的新词**：讨论中点开看过的术语卡片，和复盘一起存进知识卡片，复习时可以回看。

::: info 复盘只看你自己
复盘只依据**你本人的发言和小结**。AI 角色说过的话，不代表你懂了。所以讨论时多用自己的话回答和解释，复盘会更准确。
:::

## 知识库

每份复盘都会自动存成一张**知识卡片**。在 **知识库** 里可以看到所有卡片，分为“待复习”和“全部”。底部导航上的数字是今天要复习的卡片数量。

### 怎么复习

打开一张待复习的卡片：

1. **先凭记忆做题**，不看上次的复盘。
2. 做完题，再看上次的复盘，对照自己哪里还记得、哪里忘了。
3. 选择 **记得很清楚** 或 **还有点模糊**。

### 复习间隔

| 你的选择 | 下次复习 |
| --- | --- |
| 第一次复盘后 | 1 天后 |
| 记得很清楚 | 间隔拉长：3、7、14、30、60 天 |
| 还有点模糊 | 1 天后，重新开始 |

这是一种简单的间隔重复：记得越牢，间隔越长；一旦模糊，就重新巩固。

### 从薄弱点再讨论

在复盘页或知识卡片里点 **从薄弱点再讨论**，会用同一个概念开始一次新讨论。AI 会读取上次“还模糊”和“没讲到”的要点，以及需要纠正的理解，从那里开始追问。

## 导出

讨论记录和知识库都可以导出为 Markdown 文件，方便放进你的笔记软件。数据目前只保存在当前浏览器里，换设备或清除浏览器数据前，记得先导出。
