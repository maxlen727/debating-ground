# 快速开始

## 在线体验（演示模式）

打开 [maxlen727.github.io/debating-ground/app](https://maxlen727.github.io/debating-ground/app/) 就能用，不需要安装和注册。

在线版只有演示模式：AI 的回复来自预设模板，用来体验完整流程。推荐用“机会成本”，它有完整的示例对话和复盘。你的讨论记录和知识库只保存在这个浏览器里。

## 在电脑上运行（可以连接真实 AI）

需要先安装 [Node.js](https://nodejs.org/) 22.18 或更新版本。

1. 下载项目：在 [GitHub 仓库](https://github.com/maxlen727/debating-ground) 点 **Code → Download ZIP** 并解压，或者用 git 克隆。
2. 启动：
   - **Windows**：双击 `start.cmd`。第一次会自动安装依赖并构建，需要等一两分钟。
   - **macOS / Linux**：在项目目录里运行：
     ```bash
     npm install
     npm run build
     npm start
     ```
3. 打开浏览器，访问 http://127.0.0.1:4173 。

这时默认还是演示模式。要让 AI 真正参与讨论，继续下一步。

## 连接你的 AI

1. 在 AI 服务商那里准备一个 API Key。思辨场支持兼容 OpenAI Chat Completions 协议的服务，大多数国内外服务商都提供这种接口。
2. **建议专门为思辨场新建一个 Key，并设置消费上限。**原因见[密钥与隐私](./api-and-privacy)。
3. 在思辨场底部点 **设置**，填写：
   - **接口地址**：服务商文档里的 Base URL，通常以 `/v1` 结尾。
   - **模型名称**：服务商支持的准确模型 ID。
   - **API Key**。
4. 点 **连接并测试**。看到“已连接，测试通过”就可以开始了。

::: tip 选什么模型
讨论准备和理解复盘需要模型按固定格式返回结果。太小的模型偶尔会格式出错，界面会提示重试。一般来说，服务商的主力对话模型就够用。
:::

## 第一次讨论

1. 在 **学习** 页写下一个概念，选择一种讨论方式。不确定选哪个就用“苏格拉底追问”。
2. 点 **准备讨论**，看一眼要点和讨论题，觉得不合适可以直接改。
3. 点 **开始讨论**。接下来的事，见[一次学习的流程](./learning-flow)。
