# 安卓 App

思辨场有安卓 App，和在线版是同一套界面，装在手机上用起来更顺手，知识库也存在手机里。

## 下载安装

到 GitHub 的 [Releases 页面](https://github.com/maxlen727/debating-ground/releases) 下载 APK：

- **正式版**：标题是“思辨场 0.10.0”这样带版本号的，推荐用这个。
- **预览版**：标题是“预览版 …”，每次有新改动合进主分支时自动更新，能最早用上新功能，但可能不稳定。

在手机上打开下载好的 APK 安装。第一次安装时，手机会问是否允许浏览器（或文件管理器）“安装未知应用”，允许即可。正式版和预览版用同一个签名，可以互相覆盖安装，知识库不会丢。

## 和网页版的不同

- **连接 AI**：App 里只有“演示模式”和“我的后端”两种。没有“本机服务”，因为手机上跑不了电脑上的那个服务。用“我的后端”前，确认后端的 `ALLOWED_ORIGINS` 里有 `https://localhost`（2026 年 11 月之后部署的后端已经带上了，之前部署的见[自己部署后端](./self-host)）。
- **返回键**：先关掉打开的面板，在知识画布里先回到上一层分支，再回上一页；在学习页按返回键退出 App。
- **导出**：讨论记录和知识库的“导出”会复制到剪贴板，可以粘贴到笔记或聊天里。
- **邀请同学**：App 里生成的邀请链接指向在线版网页，同学用手机浏览器打开就能加入。
- **语音输入**：第一次用时，手机会请求麦克风权限。录音只在内存里转发给你的后端，不保存。
