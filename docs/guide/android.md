# 安卓 App

思辨场有安卓 App，是为手机重新写的原生应用：操作和在线版一样，滑动、返回键、深色模式都更顺手，知识库存在手机里，还能直接连接 AI 服务商、不用部署后端。

## 下载安装

到 GitHub 的 [Releases 页面](https://github.com/maxlen727/debating-ground/releases) 下载 APK：

- **正式版**：标题是“思辨场 0.10.0”这样带版本号的，推荐用这个。
- **预览版**：标题是“预览版 …”，每次有新改动合进主分支时自动更新，能最早用上新功能，但可能不稳定。

在手机上打开下载好的 APK 安装。第一次安装时，手机会问是否允许浏览器（或文件管理器）“安装未知应用”，允许即可。正式版和预览版用同一个签名，可以互相覆盖安装，知识库不会丢。

## 检查更新

在 **设置 → 版本与更新** 里点 **检查更新**，App 会去 GitHub 上看有没有新的正式版。有新版本时会显示更新说明，点 **下载新版本**，浏览器下载完安装包，系统会问要不要安装。新版本和现在的签名相同，直接覆盖安装，知识库不会丢。

- 也可以选 **启动时自动检查**（默认关闭）：一天最多查一次，有新的正式版才提醒，查不到就不打扰。
- 检查更新只访问 GitHub 上思辨场的发布页，不带你的任何数据。
- 装的是预览版时，会告诉你它已经比最新的正式版新。

## 从旧版升级

2026 年 11 月之前装的 App 是把网页打包起来的旧版。直接下载新版安装就行：

- 它会覆盖旧版。
- 第一次打开时，会自动把旧版里的知识库、讨论和设置搬过来，搬完会提示搬来了几张卡片。
- 旧版的数据不会被删除。万一这次没搬成，下次打开会再试。

## 连接 AI

App 里有三种方式（在“设置”里选）：

- **演示模式**：不用网络和密钥，“机会成本”能完整走一遍。
- **我的后端**：连接你[自己部署的后端](./self-host)，填后端地址和访问口令。
- **直接连接**：手机直接请求 AI 服务商，填接口地址、模型名称和 API Key，不需要部署后端。密钥怎么保存见[密钥与隐私](./api-and-privacy)。

## 和网页版的不同

- **返回键**：先关掉打开的面板，在分支里先回到上一层分支，再回上一页；在学习页按返回键退出 App。
- **导出**：讨论记录和知识库的“导出”会打开系统的分享面板，可以存成文件，或者发到笔记、聊天里。
- **朗读和语音输入**：连着自己部署的后端、后端配好讯飞时，发言旁会出现 **朗读**，输入框旁会出现麦克风。第一次点麦克风时 App 会请求录音权限；录音只在内存里转发给你的后端，不保存。说完的话填进输入框，不会自动发送。演示模式和直接连接没有语音。
- **读材料**：和网页版一样，在学习页点 **从一篇论文或文章开始**，贴上正文、链接或选一个 PDF 文件，直接围绕它讨论（[读材料](./reading)）。链接由手机自己去取。材料存在 App 的私有目录里，不进系统备份。
- **和同学一起讨论**：连着自己部署的后端时，圆桌讨论和正反辩论可以在准备页 **邀请同学一起讨论**；用直接连接时，房间开在这台手机上，同一个 Wi-Fi 里的同学用浏览器或 App 加入（[局域网房间](./multiplayer#局域网房间)）；收到邀请链接，在学习页点 **加入同学的讨论**，或者在聊天软件里把链接 **分享** 给思辨场。详见[和同学一起讨论](./multiplayer)。
