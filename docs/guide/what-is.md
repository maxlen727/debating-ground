# 思辨场是什么

思辨场是一个**用讨论来学习概念**的应用。你写下一个想弄懂的概念，比如“机会成本”“贝叶斯定理”“认知失调”，然后和 AI 讨论、被 AI 追问、或者和 AI 辩论。讨论结束后，它会告诉你哪些地方已经懂了、哪些还模糊，并把这份复盘存起来，过几天提醒你回顾。

## 为什么用讨论来学

读一遍定义，常常会产生“我懂了”的错觉。真正的理解经得起追问：换一个情境还成立吗？能举出例子吗？和相近的概念有什么不同？别人反驳时站得住吗？

思辨场把这些追问交给 AI 来做，让你在回答、解释、反驳的过程中，自己发现哪里没想清楚。它不是练口才的工具，**目标始终是把概念弄懂**。

## 适合谁

- 正在学一门课的学生：把课本上的概念放到讨论里检验一遍。
- 自学者：没有老师和同学时，找一个随时愿意追问你的对象。
- 想讲清楚一件事的人：用“反向讲解”模式，检验自己能不能讲给初学者听。

## 它和直接问 AI 有什么不同

| 直接问 AI | 思辨场 |
| --- | --- |
| AI 给出答案，你读答案 | AI 追问、质疑，你自己想答案 |
| 聊完就结束 | 结束后逐条复盘，指出误解，出检验题 |
| 不知道自己掌握了多少 | 要点清单随讨论点亮，进度一目了然 |
| 聊过就忘 | 复盘存成知识卡片，按间隔提醒回顾 |

## 现在能用到什么程度

思辨场还在早期开发阶段（v0.6）。

- **演示模式**不需要网络和密钥，可以完整体验整个流程。“机会成本”有完整示例，其他概念使用通用模板。[在线体验](https://maxlen727.github.io/debating-ground/app/)就是演示模式。
- **真实 AI**有两种用法：[自己部署一个后端](./self-host)，在网页上连接它；或者在电脑上运行思辨场。都使用你自己的 AI 服务 API Key，见[密钥与隐私](./api-and-privacy)。
- 安卓 App 正在开发中，见[路线图](../product/roadmap)。
