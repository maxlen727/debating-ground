# 密钥与隐私

要让 AI 真正参与讨论，需要使用你自己的 AI 服务 API Key。把密钥交给任何软件都需要信任，这一页讲清楚它去了哪里、我们怎么尽量让你**不需要**信任我们。

## 先说一句实话

只要密钥经过某个服务器，那台服务器在使用它的那一刻就能看到它。我们无法用技术手段向你证明“我们没有偷看”。所以思辨场的方向是：**尽量让密钥不经过我们**；必须经过的时候，让你可以自己掌控那台服务器。

## 现在：在你自己的电脑上运行

当前版本（v0.5）的真实 AI 只能在你自己的电脑上使用：

- 思辨场在你的电脑上启动一个本机服务，只接受这台电脑上的访问（`127.0.0.1`）。
- 你在设置里填写的密钥只保存在这个本机服务的**内存**里，不写入硬盘、浏览器存储、日志、讨论记录或知识库。
- 讨论时，本机服务带着密钥直接请求你填写的服务商地址，中间不经过思辨场团队的任何服务器。
- 点 **断开并清除** 或关闭本机服务，密钥就会被清除。

所以现在，密钥只会出现在两个地方：你的电脑，和你选择的 AI 服务商。

## 规划中的两条路

### 安卓 App：单人模式在手机上直接调用服务商

网页受浏览器的跨域限制，必须有一个服务端帮忙转发请求；原生 App 没有这个限制。安卓 App 的单人模式会：

- 把密钥保存在系统的安全存储（Android Keystore）里。
- 由手机直接请求你选择的 AI 服务商。

**密钥只会离开你的手机、发往服务商，思辨场团队的服务器全程碰不到它。**你和一群 AI 讨论，是思辨场最主要的使用场景，这个场景完全不需要我们的后端。

### 自己部署后端

多人联网讨论、在网页里使用真实 AI 时，需要一个后端来转发请求、主持讨论。我们会提供一个开源的后端（运行在 Cloudflare Workers 上），并支持**一键部署到你自己的 Cloudflare 账号**，免费额度就够个人和小组使用。

部署在你自己的账号里，代码你能看到，运行环境由你控制，你只需要信任你自己。

## 不管用哪种方式：给密钥设上限

这是对你最实在的保护：

1. **专门为思辨场新建一个 API Key**，不要和其他软件共用。
2. 在服务商控制台给这个 Key **设置消费上限**，比如每月几十元。
3. 能限定可用模型的话，只开放你要用的模型。
4. 不用了，或者怀疑泄露了，**随时作废**这个 Key，再换一个新的。

这样即使发生最坏的情况，损失也有上限。

## 你的讨论内容

- 讨论记录、复盘和知识库保存在**你的浏览器**里，不会上传给思辨场团队。
- 使用真实 AI 时，讨论内容（概念、讨论题、角色背景和对话记录）会发送给**你选择的 AI 服务商**，由他们的隐私政策约束。
- 思辨场不接入任何第三方统计或广告。
- 所有代码在 [GitHub](https://github.com/maxlen727/debating-ground) 上公开，你可以自己检查。
