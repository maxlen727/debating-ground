# 读材料

想弄懂一篇论文或文章，可以从材料开始：研读助手先读一遍，拆出里面值得弄懂的技术点，你挑一个，再用苏格拉底追问或圆桌讨论把它聊透。

::: info 目前只在网页版
第一版先做了网页版，支持粘贴正文。安卓 App、文章链接和 PDF 还在做。
:::

## 怎么用

1. 在学习页点 **从一篇论文或文章开始**。
2. 把正文贴进来，标题可以不写。带着小节标题更好（比如“1 引言”“2.1 方法”“## 结论”），研读助手会按节来读；没有标题的材料会按长度切成几部分。想先看看效果，点 **用示例文章试试**。
3. 点 **开始研读**。研读助手一步一步地读，每一步在做什么都显示在“研读过程”里：先看大纲，再挑几节读，必要时在原文里搜一个词，最后整理出一张 **技术点地图**。
4. 地图上每个技术点写着它在材料里起什么作用、在哪几节（§2 表示第 2 节）、要先懂什么。挑一个，选 **追问** 或 **圆桌**，点 **从「…」开始讨论**。

## 讨论时

- AI 手里有这个点的 **原文节选**（它所在的几节）。讲到材料里的内容时以原文为准，自己补充的会说明是补充，不把材料没说的话说成材料说的。
- 讨论页的工具栏里有 **原文**，随时翻看这几节。
- 复盘照常整理进这个概念的笔记，来源里会写着“读《材料标题》”。以后再读别的材料碰到同一个概念，新的理解会接着沉淀进同一篇笔记。

## 研读助手是怎么工作的

它是一个很小的 Agent：每一步只做一个动作（读某几节、搜一个词，或者整理出地图），看完结果再决定下一步，最多走 8 步。

- **它只读，不改**：工具只能读原文、搜原文，不能做别的事。
- **原文是资料，不是指令**：论文或网页里如果藏着“忽略之前的指令”之类的话，它不会照做。
- **只发需要的部分**：研读时，只把它要读的那几节发给 AI；讨论时，只带这个点的节选，不会每次都把整篇材料发出去。

## 材料存在哪

完整的材料只保存在这台设备的浏览器里（IndexedDB），不进存档、导出文件和讨论记录。“读过的材料”列表里可以重新打开或删除。清除浏览器数据会把它们一起清掉。

演示模式下，研读助手按小节标题整理地图，不会真的读懂原文；连接 AI 以后才会读原文、写出每个点的作用。
