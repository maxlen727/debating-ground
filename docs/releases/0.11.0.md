# 思辨场 0.11.0

这一版把“弄懂一个概念”往前推了两步：知识库变成了一个概念一篇的笔记，越讨论越完整；还可以直接围绕一篇论文或文章讨论。同学之间也不用部署后端了，在同一个 Wi-Fi 里就能一起讨论。

## 从旧版升级

直接安装，不用先卸载。第一次打开时，原来的知识卡片会按概念合并成笔记，旧的存档文件原样保留。

## 概念笔记

- 知识库改成**一个概念一篇笔记**：每次讨论完的复盘都沉淀进去，你的说法、例子、容易错的地方越积越完整。
- “讲给 AI 听”搬进了概念笔记里：已经有些理解时，从笔记里开始讲，讲完的复盘会更新这篇笔记。
- 追问和圆桌讨论里，遇到想深挖的词，可以从那句话**展开一个分支**单独聊，聊完带回主干。

## 读材料

- 在学习页点 **从一篇论文或文章开始**：贴正文、贴链接（arXiv 论文、网页文章），或者**直接选 PDF 文件**，然后选追问或圆桌，围绕材料本身讨论。
- 长材料不会每次整篇发给 AI，聊到哪部分就翻到哪部分；讨论时随时可以翻看原文。
- 复盘既沉淀进核心概念的笔记，也沉淀进这篇材料自己的笔记。
- 有的网页读不到（要登录、有反爬）时，可以在 App 内置的浏览器里打开，登录或通过验证后点 **用这一页**。
- 链接由手机自己去取，PDF 只在手机上解析，都不经过别的服务器。

## 局域网一起讨论

- 用“直接连接”时，**手机就能当房主**：同一个 Wi-Fi 里的同学用 App，或者直接用浏览器打开邀请链接加入，不用装 App。
- 邀请面板有**二维码**，同学扫一下就能进。
- 同学拿不到你的 API Key。局域网里的连接不加密，只在家里、宿舍、教室这样信得过的网络里用。

## 其他

- **检查更新**：设置里可以手动检查，也可以打开“启动时自动检查”，有新的正式版才提醒。
- **界面**：
  - 分段选择改成和 iOS 一样的中性滑块，选中了什么一眼就看得出。
  - 内容滚到底部按钮下面时，只在边上淡出一小段，不再糊成一片。
  - 各页面的说明文字精简了，内容排在前面。
  - 按下回弹、横向滚动渐隐、点空白处收起键盘。

## 网页版

网页版同样有概念笔记、读材料（正文、链接、PDF）、分支和精简后的界面；电脑上运行 `npm run server:lan` 就能当局域网房主。

## 还没在真机上验证的

下面这些都有自动测试和截图测试，但发版时还没在真机或真实模型上完整试过，用起来不对请到 GitHub 提 issue：

- 扫二维码加入；同学用浏览器加入手机当房主的房间。
- 手机读链接、内置浏览器、选 PDF。
- 用真实模型围绕材料讨论（提示词没跑过真实模型的评测）。
