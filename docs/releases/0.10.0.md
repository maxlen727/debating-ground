# 思辨场 0.10.0

第一个原生安卓正式版。安卓 App 从“网页套壳”换成了用 Kotlin + Jetpack Compose 重写的原生 App。

## 从旧版升级

直接安装，不用先卸载。第一次打开时，App 会把旧版的知识库搬过来，旧数据不会删除。

## 原生 App 有什么

- **完整的学习流程**：
  - 写下概念，选讨论方式：苏格拉底追问、圆桌讨论、正反辩论、知识画布。
  - 讨论、写小结，结束后生成理解复盘，存成知识卡片。
- **三种 AI 来源**：
  - **演示模式**：离线可用。
  - **我的后端**：连接自己部署的 Cloudflare Worker。
  - **直接连接**：App 直接调用 AI 服务商，API Key 用系统密钥库加密保存，只在这台手机上。
- **和同学一起讨论**：开房间、邀请；在聊天软件里把邀请链接“分享到思辨场”就能加入。
- **朗读和语音输入**：连着自己的后端、后端配好讯飞时出现。
- **知识库**：卡片多了可以搜索。可以打开复习提醒（默认关闭），有到期的卡片时每天提醒一次。
- **界面**：
  - 悬浮的磨砂导航和按钮。
  - 换页、面板、消息都有连贯的动效。
  - Android 14 起支持返回手势预览。
  - 几个关键时刻有轻触感。

## 网页版

- 学习页的开始按钮和 App 一致。
- 知识库可以搜索。
- 背景改成预渲染的图，滚动和打字时不再卡。
