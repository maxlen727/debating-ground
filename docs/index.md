features:
  - title: 从概念出发
    details: 写下一个概念，AI 先拆出真正理解它需要掌握的几个要点，再出一道适合讨论的题目。开始前都可以修改。
  - title: 四种讨论方式
    details: 苏格拉底追问、圆桌讨论、反向讲解、正反辩论。刚入门、换角度、检验讲解能力、碰到争议，各有适合的方式。
  - title: 随时追问
    details: 轻点任意一句 AI 的发言，让它换个说法、举个例子，或者说清楚哪些是事实、哪些是观点。卡住了可以要一条只给思路的提示。
  - title: 停下来说说
    details: 讨论进行到一半，会请你用自己的话写一句小结。AI 对照要点告诉你哪里说对了、最关键的遗漏是什么。
  - title: 复盘只看你自己
    details: 结束后逐条评估要点的掌握情况，指出需要纠正的理解，出几道检验题。只依据你本人的发言，AI 说过的不算你懂了。
  - title: 落盘，再回顾
    details: 每次复盘都存成一张知识卡片，按 1、3、7、14 天的间隔提醒你回顾。复习时先凭记忆做题，再看上次的复盘。
