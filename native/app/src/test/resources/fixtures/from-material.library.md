# 思辨场知识库

# 机会成本

做一个选择时，放弃掉的那些选项里最好的一个的价值，就是这个选择的机会成本。

**什么时候想到它**：在几个选项之间做决定，想知道“选这个到底花了什么”的时候。

## 要点

- [掌握] 放弃的最佳选择：能用打工和家教的例子说清楚。（我说过：“机会成本就是做一件事放弃的另一件事最好的价值。”）
- [模糊] 只算次优那一项：一开始把所有放弃的选项加在了一起。（我说过：“机会成本是放弃的东西。”）
- [掌握] 包含隐性代价：主动提到了时间和休息。（我说过：“比如我周末去打工，就放弃了在家复习的收获。”）
- [模糊] 区别于沉没成本：知道健身卡不该算，但理由说得不完整。
- [没讲到] 用于比较决策：还没有用它做过一次完整的选择比较。

## 例子

- 周末去打工赚 300 元，放弃了在家复习的收获。

## 易错

- ~~机会成本是所有放弃的选项加起来。~~ → 只算放弃的选项中价值最高的那一个，因为你一次只能选一个。

## 边界

- 不是已经花掉、拿不回来的钱：那是沉没成本，不该影响现在的选择。

## 相关概念

沉没成本、边际效用

## 自检

1. 小王周六可以打工赚 300 元、做家教赚 500 元，或者在家休息。他选了打工，他的机会成本是多少？为什么不是 800 元？
   - 参考：500 元。只算放弃的选项里价值最高的那一个（家教），一次只能选一个，不能把放弃的都加起来。
2. 已经付了 200 元、不能退的演唱会门票，当天你更想去加班。这 200 元该不该影响你的决定？
   - 参考：不该。钱已经花了、拿不回来，选哪个都一样，是沉没成本；只比较去看和去加班各自接下来的得失。
3. 用机会成本比较一下：毕业后直接工作，还是读研三年？各列出你会放弃什么。
   - 参考：读研放弃三年的工资、工作经验和人脉；直接工作放弃学历带来的机会。两边都算上放弃的最好选项，再比较。
